# Legacy / Respaldo

Este directorio guarda material apartado del runtime activo (`game/`) para limpieza del proyecto sin perder trabajo.

## Estructura

- `docs_archive/`: documentación histórica movida desde `docs/` (último commit <= 2026-03-18, criterio de antigüedad >= 7 días al 2026-03-25).
- `gameplay_disabled/typing/`: prototipo de juego de tipeo.
- `gameplay_disabled/panels/`: editor de puntos y pre-combate apartados temporalmente.
- `gameplay_disabled/panels_png/`: scripts de paneles/HUD con PNG en cuadros apartados para rediseño.
