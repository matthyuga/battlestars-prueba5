# type-bleach

Paquete aislado del minijuego de tipeo (Typing Lab) para moverlo a un proyecto Ren'Py separado.

## Contenido

- `game/09_TYPING_LAB.rpy`: lógica completa del minijuego (letras, palabras y frases).
- `game/script.rpy`: entrada mínima para iniciar directamente el minijuego.

## Uso rápido

1. Crea un proyecto nuevo en Ren'Py (vacío).
2. Copia el contenido de esta carpeta `type-bleach/` dentro del proyecto nuevo.
3. Ejecuta el proyecto: iniciará directamente en el minijuego.

## Nota

Este paquete está pensado para ser el punto de partida de una sesión nueva centrada solo en tipeo.
