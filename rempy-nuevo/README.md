# rempy-nuevo

Proyecto base (Ren'Py) con **solo los scripts del minijuego de tipeo**.

## Contenido

- `game/09_TYPING_LAB.rpy`: lógica/pantallas del Typing Lab.
- `game/script.rpy`: entrada mínima que salta directo al minijuego.

## Cómo usarlo

1. Crea un proyecto nuevo en Ren'Py Launcher.
2. Copia estos archivos dentro de la carpeta `game/` del proyecto nuevo.
3. Ejecuta el proyecto.

> Este paquete deja fuera imágenes/otros sistemas para mantener el minijuego aislado.
