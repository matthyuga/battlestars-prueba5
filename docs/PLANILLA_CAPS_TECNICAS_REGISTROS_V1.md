# Planilla de Caps por Registro (Reg 0–50) — PvP/PvE

Esta planilla usa una **base única** por registro y muestra el valor resultante para **(PvP)/(PvE)**.

- PvE usa 100% de la base.
- PvP usa factor por tier para controlar burst/tanqueo en combate entre jugadores.
- Fórmula visual usada en la tabla: `base (pvp/pve)`.

## Factores PvP por tier

- D/C/B/A: 1.00
- S: 0.95
- SS: 0.85
- SSS: 0.75

## Notas de uso

1. El cap de cada técnica en un registro se obtiene desde su familia (ofensiva o defensiva).
2. Técnicas especiales pueden aplicar ajuste manual adicional (no rompen la base).
3. Para técnicas nuevas: iniciar con fallback global y luego registrar tabla propia.
